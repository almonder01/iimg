Multi-state interactions

Named states drive visibility and colors. Select an object above to bind its style or actions. State colors override the base color. Changing a maximum extends/truncates its bound styles; out-of-range set actions reject the change. These files require Core 1.0 export.

Finite motion

Move the selected object's bounding box between two positions while a state has the chosen value. Motion overrides the base placement; the design shows time zero. Both endpoints must fit after a size edit.

Text and image description

Text uses this device's system fonts and becomes an opaque PNG in the file. Arabic shaping is performed here; exported pixels stay fixed in every reader. Keep source JSON for re-editing. Updating a shared asset updates every linked image.
