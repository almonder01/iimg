# IIMG license policy

Project code is licensed under Apache-2.0. Documentation and specifications are licensed under CC BY 4.0. The corresponding legal texts are [LICENSE](LICENSE) and [LICENSE-CC-BY-4.0](LICENSE-CC-BY-4.0). The project attribution is recorded in [NOTICE](NOTICE).

Project code includes the Rust crates, viewer applications, scripts, fixture generators and test implementations. Documentation includes specifications, machine-readable schemas, RFCs and contributor guides. Attribute project material to IIMG contributors and preserve more specific copyright notices where supplied. The project source is available at [almonder01/iimg](https://github.com/almonder01/iimg).

Project-authored fixture documents, embedded artwork, portable trace data and authoring examples are available under Apache-2.0. Their manifests record the license and provenance. The repository owner authorized Apache-2.0 as the sole license for project code and fixtures on 2026-11-05. Documentation and specification licensing remains CC BY 4.0.

Earlier published revisions offered project code and fixtures under MIT OR Apache-2.0. This update applies to the current revision and future contributions under this policy; it does not withdraw permissions already granted for earlier published revisions.

Third-party components retain their own licenses and copyright notices. Review packages include the Cargo dependency license files under `licenses/cargo/`, with an inventory and SHA-256 values. The inventory covers the resolved dependency closure, including build dependencies. Review additional platform tooling and bundled components when preparing Android or other distributions.
